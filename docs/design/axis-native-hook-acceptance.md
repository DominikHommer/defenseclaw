[Contract inventory](../../cli/defenseclaw/inventory/hook_contracts.json). **No real vendor hook is qualified by this source-only review.**

Each case needs a pinned vendor binary/version and OS runtime, actual hook registration and correlated request, a benign allow, a pre-action deny of a private sentinel write, separate tamper/silence/revocation trials, and proof that the native owner, descendants, binding, endpoint and assets cleaned up. A helper-only verdict or PATH lookup does not qualify a case. WSL counts as Linux.

D = official native platform support for the named product/CLI, with hook behavior still unqualified. ? = exact native hook surface unverified or official claims conflict. X = official CLI excludes native OS. Verify the executable for the product under test: Cursor CLI is `agent`, while `cursor` names the editor; Antigravity documents `agy`; Omnigent documents `omni` while the repository also probes `omnigent`. A PATH lookup proves neither binary identity nor hook loading. The matrix is documentation review, with no vendor execution or credential qualification.

Critical upstream behavior: [Copilot command PreToolUse](https://docs.github.com/en/copilot/reference/hooks-reference) denies on non-timeout error but fails open on timeout; HTTP transport failures also fail open. [Cursor permission hooks](https://prod.cursor.com/docs/hooks) block invalid JSON and exit 2 but other nonzero exits proceed. [OpenHands V1 CLI](https://docs.openhands.dev/openhands/usage/cli/quick-start) requires WSL on Windows; [Amp CLI](https://ampcode.com/docs/cli) documents Windows through WSL; [OpenCode 1 and 2](https://docs.opencode.ai/docs/) share the same command.

DefenseClaw must retain the same policy decision, binding, revocation and owned cleanup across providers. A vendor timeout or silence cannot be accepted as enforcement: the qualified runtime must stop or refuse that session. Publish a capability only after the actual vendor/version/OS case passes. A missing native vendor runtime must report unavailable; it must not silently select WSL, OpenShell or a different connector.
